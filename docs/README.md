- `DEVOPS.md` - Local build, environment setup, Docker usage, and Go-specific operational commands.
- `STAGE2_DEVELOPMENT_PLAN.md` - Feature roadmap and architecture plan for Stage 2 industrial automation development.

- `STAGE2_QUALITY_AND_TRACEABILITY.md` - Reference guide for quality inspection and traceability workflows in Stage 2.

- `STAGE2_PRODUCTION_ANALYTICS_AND_METRICS.md` - Reference guide for production analytics and metrics in Stage 2.
- `STAGE2_GOVERNANCE_AND_MULTISITE.md` - Reference guide for Governance, multi-site and business continuity (stage 2 increment 1: orgs/sites/roles).
